# features

Ce dossier contient la logique metier du solver.

## Role

- decouper le solver par domaines fonctionnels
- isoler les responsabilites metier
- rendre les traitements plus lisibles et plus maintenables

## Sous-dossiers

- `cv` : vision par ordinateur
- `ground` : geometrie et calibration du terrain
- `players` : joueurs, timeline et analytics
- `uwb` : acquisition, calcul et orchestration UWB
