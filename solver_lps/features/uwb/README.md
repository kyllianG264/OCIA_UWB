# uwb

Ce dossier contient la partie UWB du solver.

## Role

- recuperer les mesures UWB
- calculer les positions 2D ou 3D
- orchestrer les modes realtime et review

## Sous-dossiers

- `acquisition` : lecture et collecte des mesures
- `calculus` : calcul des positions
- `orchestration` : composition des modes UWB
