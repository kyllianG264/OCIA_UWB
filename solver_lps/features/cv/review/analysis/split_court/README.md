# split_court

Ce dossier contient l'analyse CV pour les cas split court.

## Role

- traiter les observations separees par moitie de terrain
- filtrer, dedoublonner et rattacher les trajectoires
- produire un resultat fusionne stable

## Sous-dossiers

- `data` : I/O du pipeline split court
- `domain` : filtres et regles metier split court
