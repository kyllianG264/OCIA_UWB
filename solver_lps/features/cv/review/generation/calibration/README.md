# calibration

Ce dossier contient la generation de calibration pour la CV.

## Role

- lire le terrain et les videos utiles
- calculer les transformations de projection
- produire les fichiers de calibration

## Sous-dossiers

- `data` : lecture et ecriture des fichiers
- `domain` : calculs de calibration
- `presentation` : outils de lancement ou interfaces de calibration
