# grayzone

Ce dossier contient l'analyse des zones non visibles par la camera.

## Role

- modeliser la gray zone
- lire les donnees necessaires
- produire des sorties exploitables

## Sous-dossiers

- `application` : orchestration du cas d'usage gray zone
- `data` : lecture et ecriture
- `domain` : modele metier
- `presentation` : points d'entree CLI
- `tests` : validation automatisee
