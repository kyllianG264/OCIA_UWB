# players

Ce dossier contient la logique liee aux joueurs.

## Role

- representer les joueurs et leurs frames
- centraliser le registre des joueurs
- fournir timeline et analytics

## Sous-dossiers

- `application` : cas d'usage comme la timeline
- `data` : lecture de donnees joueurs
- `domain` : modeles et logique joueurs
- `tests` : validation automatisee
