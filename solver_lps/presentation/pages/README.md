# pages

Ce dossier contient les pages principales du solver.

## Role

- exposer les ecrans accessibles depuis l'application
- afficher la review, la navigation et les vues principales

## Exemples

- `home_page.py`
- `estimation_2d_page.py`
- `cv_tracking_page.py`
- `udp_viewer_page.py`

## Sous-dossiers
