# assets

Ce dossier contient les donnees utilisees ou produites par le solver.

## On y trouve

- les terrains par sport
- les sets de travail
- les fichiers d'entree
- les sorties d'analyse
- les modeles utilises par la CV

## Organisation

- `basket` : assets lies au basket
- `volley` : assets lies au volley
- `models` : modeles utilises par les pipelines de vision

## Regle

On y stocke les fichiers de travail du solver, pas la logique Python.
